# DSA

C++ practice solutions for data structures and algorithms — arrays, sorting, hashing, recursion, and other patterns worked through while preparing for placements.

## Structure

- `arrays/` — array problems (second largest element, unique sorted, etc.)
- `sorting/` — sorting algorithm implementations
- `striver_course/` — exercises following Striver's DSA course (basic maths, patterns, recursion, hashing)
- Root-level `.cpp` files — standalone problems (e.g. two sum)
